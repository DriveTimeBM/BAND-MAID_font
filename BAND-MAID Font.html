Kobato's Po

Two ways to summon ぼ.

The PO glyph (Kobato's signature ぼ) is mapped to both the Unicode hiragana ぼ and an OpenType ligature triggered by -PO-.

1 · Literal Unicode

Type the actual hiragana character ぼ (U+307C). Works anywhere the font is loaded.

ぼ

2 · Ligature keyword

Type the 4-character sequence -PO-. OpenType ligature substitution swaps it for the PO glyph automatically.

-PO-

Use it on a web page

Drop-in CSS.

After downloading the .ttf, host it next to your page and paste this into your stylesheet.

/* in your CSS */ @font-face { font-family: 'BAND-MAID'; src: url('BAND-MAID-Display.ttf') format('truetype'); font-display: swap; } /* anywhere you want it */ .band-name { font-family: 'BAND-MAID', sans-serif; font-feature-settings: "liga" on; /* needed for -PO- ligature */ }
